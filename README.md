# Ocean Watch 🌊

Application de signalement de pollution côtière pour citoyens, collectivités et ONG.

## 🚀 Démarrage rapide

### Installation
```bash
npm install
```

### Développement
```bash
npm run dev
```

## 📁 Structure du projet

```
├── src/                    # Frontend React + TypeScript
│   ├── components/         # Composants réutilisables
│   ├── pages/             # Pages de l'application
│   ├── lib/               # Utilitaires et données mockées
└── supabase/              # Configuration Supabase (optionnel)
```

## 🔧 Technologies

### Frontend
- **React 18** + TypeScript
- **Tailwind CSS** pour le style
- **React Router** pour la navigation
- **Lucide React** pour les icônes

## 🌊 Fonctionnalités

- ✅ Signalement de pollution avec géolocalisation
- ✅ Carte interactive des signalements
- ✅ Dashboard pour collectivités/ONG
- ✅ Données mockées pour démonstration
- ✅ Interface responsive
- ✅ Application entièrement frontend

## 🎯 Types de pollution supportés

- 🔴 Déchets plastiques
- 🟠 Hydrocarbures  
- 🟢 Déchets organiques
- 🟣 Produits chimiques
- ⚫ Autre

## 📱 Responsive Design

L'application est optimisée pour tous les appareils (mobile, tablette, desktop).
